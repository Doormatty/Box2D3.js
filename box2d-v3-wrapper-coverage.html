Box2D v3 Wrapper Coverage Matrix

Static inventory of Box2D v3.1.1 concepts that could be exposed through the JavaScript/Wasm wrapper, compared against the current wrapper surface in box2d.v3.js, v3/box2d_v3_shim.c, and build-v3.ps1.

Status is concept-level, not one-to-one native API parity. A concept is "partial" when useful wrapper behavior exists but some native functions, shape variants, callbacks, or diagnostics are still missing.

Implemented Partial Missing Internal Low Priority
22 concept groups with usable wrapper coverage
13 groups with partial coverage or selected omissions
8 groups still missing or intentionally deferred
4 highest-value next targets: weld joints, world profiling/counters, debug draw, shape casts
Current wrapper shape: The wrapper is intentionally not a raw binding of every B2_API function. It uses small JS handle objects backed by wasm-side ID tables, exposes common gameplay/editor operations, and avoids callback-heavy APIs unless there is a clear consumer.
